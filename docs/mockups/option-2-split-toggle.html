Connect to this gateway

How to use the gateway from any OpenAI-compatible client. Listen addresses and endpoints reflect the gateway's default configuration (gateway.toml); the master key below is a placeholder.
Listen addresses
Loopback127.0.0.1:8787
Tailscale / CGNAT address100.92.90.99:8787
Allowed listen hosts: loopback (127.0.0.0/8, ::1, localhost), CGNAT (100.64.0.0/10 — the Tailscale default range), and ULA (fc00::/7). Wildcard (0.0.0.0) and plain RFC 1918 LAN addresses are refused by design.
Endpoint (base URL)
http://127.0.0.1:8787/v1
Tailscale / CGNAT address: http://100.92.90.99:8787/v1
OpenAI-compatible surface on port 8787: POST /v1/chat/completions, POST /v1/responses, GET /v1/models. There is no /v1/messages path on the gateway itself — Anthropic Messages-style clients are handled per provider instance (point an anthropic-style instance, e.g. the anthropic alias, at its Anthropic-compatible upstream).
Master API key
sk-shimmer-••••••••••••••••••••••••
Generated on first run; it encrypts the secrets file — copy and store it somewhere safe. Mirrors the master-key banner pattern in the real UI.
Install as a provider
  1. Point your client's base_url at the endpoint above (e.g. http://127.0.0.1:8787/v1).
  2. Use the master key as the api_key.
  3. Choose a configured alias (e.g. small) as the model name.
Config snippet
{
  "base_url": "http://127.0.0.1:8787/v1",
  "api_key": "sk-shimmer-9f2b1c7e4d8a6f0b3c5e7a9d1f2b4c6e",
  "model": "small"
}
OpenAI-compatible JSON config — works in any client that accepts base_url / api_key / model.
